# 支付宝沙箱怎么准备（途个惊喜）

> 用途：电脑/手机 **跳转收银台** 联调，不产生真实扣款  
> 产品：电脑网站支付 `alipay.trade.page.pay`（答辩演示优先）  
> 官方入口：[新版沙箱](https://open.alipay.com/develop/sandbox/app)

你要准备的不是「赚钱」，而是下面这几样：**沙箱 APPID、密钥、网关、买家账号、可被支付宝访问的回调地址**。

---

## 1. 要拿到哪些东西

| 配置项 | 从哪来 | 放哪 |
|---|---|---|
| `app-id` | 沙箱应用页上的 APPID（和正式应用不是同一个） | `application-local.yml` |
| `private-key` | 你自己的应用私钥（RSA2） | 同上，**不要提交 Git** |
| `alipay-public-key` | 沙箱「开发信息」里的支付宝公钥 | 同上 |
| `gateway` | 新版沙箱固定地址 | 见下 |
| 沙箱买家账号 + 密码 | 沙箱页「沙箱账号 / 测试账号」 | 只用来登录收银台付款 |
| `notify-url` | 你的公网 HTTPS + `/api/v1/pay/notify/alipay` | 沙箱能访问到的地址 |
| `return-url` | 用户端结果页，如 `https://你的域名/#/pay/result` | 付完跳回来 |

新版沙箱网关（代码里必须用这个，不要用正式网关）：

```text
https://openapi-sandbox.dl.alipaydev.com/gateway.do
```

若控制台仍是旧版，右上角点 **升级沙箱环境**。旧 APPID、旧网关 `openapi.alipaydev.com` 在新沙箱会调不通。

---

## 2. 按顺序做

### 第 1 步 登录开放平台

1. 用**已实名**的支付宝账号打开 [open.alipay.com](https://open.alipay.com)。  
2. 进控制台。没有开发者身份就按提示完成认证（个人开发者即可做沙箱）。

### 第 2 步 打开沙箱

浏览器打开：

[https://open.alipay.com/develop/sandbox/app](https://open.alipay.com/develop/sandbox/app)

沙箱应用是平台**自动创建**的，不用自己再建一个「途个惊喜」应用。页面上复制 **APPID**。

在产品列表里确认有 **电脑网站支付**（跳转收银台）。没有就在沙箱产品里开通/勾选。

### 第 3 步 配密钥（建议先用系统默认）

在沙箱 **开发信息**：

1. 加签方式选 **公钥**（不要一上来上证书，课设更简单）。  
2. 签名 **RSA2**。  
3. 两种做法：  
   - **系统默认密钥**（最快）：页面直接复制「应用私钥」「支付宝公钥」。  
   - **自定义密钥**：用[开放平台密钥工具](https://opendocs.alipay.com/common/02kkv7)生成 RSA2 → 私钥自己留着 → 公钥贴到沙箱 → 再复制页面上的「支付宝公钥」。

后端用的是：

- 应用私钥 = 你的（加签）  
- 支付宝公钥 = 支付宝的（验异步通知）

两者不要贴反。私钥保持一行或标准 PEM，和 SDK 要求一致。

### 第 4 步 记下沙箱买家

打开 **沙箱账号 / 测试账号**：

| 账号 | 干什么 |
|---|---|
| 商家账号 | 对应沙箱商户，一般不用来付款 |
| **买家账号** | 在收银台登录、付钱 |

新版会预置余额。旧版常见密码是 6 个 `1`（以控制台显示为准）。余额不够就在账号页 **充值**（假钱）。

只支持沙箱余额支付，不要绑真银行卡。

### 第 5 步 付款用什么客户端

| 场景 | 怎么付 |
|---|---|
| 笔记本演示电脑网站支付 | 跳到收银台后，用 **沙箱买家账号登录网页** 付；或用 **沙箱版支付宝 App 扫码** |
| 手机网站支付 wap | 真机浏览器跳转；扫码仍要用沙箱 App |
| 正式支付宝 App | **不能**付沙箱单，会报错 |

沙箱钱包：沙箱页左侧 **沙箱工具 → 沙箱钱包**，目前主要是 **Android**。只有 iPhone / 没安卓时，用电脑收银台 **账号登录支付**。

必须用**新版沙箱买家**登新版沙箱钱包，旧账号登不进去。

### 第 6 步 回调必须公网

支付宝服务器要 POST 你的 `notify-url`。`localhost`、`127.0.0.1` **收不到**异步通知，订单会一直待支付。

做法任选其一：

- [cpolar](https://www.cpolar.com/) / natapp / ngrok 把本地 `8080` 映射成 `https://xxxx.cpolar.cn`  
- 已有备案/测试服务器，直接配域名

示例：

```text
notify-url: https://xxxx.cpolar.cn/api/v1/pay/notify/alipay
return-url: https://xxxx.cpolar.cn/#/pay/result
```

`return-url` 是浏览器跳回，本机也可以；**入账只认 notify**。穿透地址变一次，yml 里两个 URL 都要改，重启后端。

沙箱里若有「授权回调地址 / 网关地址」栏，填同一套公网域名。

### 第 7 步 写进本地配置（不要提交）

`server/src/main/resources/application-local.yml`（已 gitignore）：

```yaml
alipay:
  sandbox: true
  gateway: https://openapi-sandbox.dl.alipaydev.com/gateway.do
  app-id: 沙箱APPID
  private-key: 应用私钥
  alipay-public-key: 支付宝公钥
  sign-type: RSA2
  charset: UTF-8
  notify-url: https://你的穿透域名/api/v1/pay/notify/alipay
  return-url: https://你的穿透域名/#/pay/result
  product: page   # 演示用电脑网站；手机再改 wap
```

启动加 `spring.profiles.active=local`。

电脑网站支付 `product_code` 为 `FAST_INSTANT_TRADE_PAY`；手机网站为 `QUICK_WAP_WAY`。接口层已按 `page` / `wap` 区分，见 `docs/接口设计.md`。

## 3. 怎么知道准备好了

1. 用户端开盒 → 跳到支付宝沙箱收银台（不是 404、不是正式支付宝）。  
2. 用沙箱买家付 0.01～售价都能成功（金额用订单真实售价）。  
3. 后端日志收到 notify，验签通过，应答 `success`。  
4. 前端轮询订单变成 `opened`，出现翻牌线路。  
5. 再付同一单，notify 重复到达但订单仍只有一次开盒（幂等）。

## 4. 常见卡点

| 现象 | 原因 |
|---|---|
| 签名错误 | 公私钥贴反、不是 RSA2、私钥带了多余空格/引号 |
| 无效的 AppID | 用了正式应用 APPID，或旧版沙箱 APPID |
| 收银台能付、站内一直待支付 | `notify-url` 不是公网，或本地防火墙挡了 POST |
| 扫码失败 | 用了正式支付宝，没用沙箱 App / 沙箱买家 |
| iOS 没法装沙箱钱包 | 改用电脑收银台账号登录支付 |
| 金额不对 | 支付宝单位是 **元**，两位小数；不要把分直接传成元 |

官方说明：[电脑网站支付如何使用沙箱](https://opendocs.alipay.com/support/01rfvs) · [沙箱账号 FAQ](https://opendoc.alipay.com/support/01raze)

## 5. 和正式环境的差别（以后再换）

沙箱跑通后，上线要换成：正式 APPID、正式密钥、网关 `https://openapi.alipay.com/gateway.do`、商家平台签约「电脑网站支付」、真实 `notify-url`。业务代码不用改，只换配置。
