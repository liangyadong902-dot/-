## 自动化脚本

- `scripts/acceptance/phase34-api.mjs`：人格、AI、日记、5 角色权限、审计和统计。
- `scripts/acceptance/phase34-mock-transaction.mjs`：仅在受控环境临时开启模拟支付，验证开盒、退款和资产回落。
- `scripts/acceptance/admin-visual.cjs`：管理端成功、空、错误和只读权限状态。
- `scripts/acceptance/phase34-cleanup.sh`：按 7 位 run ID 清理验收库和 Redis 中的临时数据，并拒绝对 `tuge_acceptance` 以外的数据库运行。

脚本只通过环境变量接收服务地址、管理员凭据、数据库和 Redis 配置，不写入 DeepSeek、微信或支付宝密钥。
