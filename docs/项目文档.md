# Spec: 途个惊喜 Vue 重构

> 来源原型：`prototype/index.html`（单文件 HTML + Tailwind + 原生 JS）
> 文档状态：待确认后进入实现
> 产品定位：盲盒式惊喜旅行 H5，口号「随盒出发，途个好心情」

---

## 当前假设（请先纠正）

1. **技术栈**：Vue 3 + Vite + TypeScript + Vue Router + Pinia + Tailwind CSS + Remix Icon。
2. **形态**：移动端 H5（`max-w-md` 居中），第一期不做微信小程序、不做原生 App。
3. **后端**：第一期纯前端，数据写 `localStorage`，AI 聊天与旅行日记沿用原型的关键词/模板模拟，不接真实大模型与支付。
4. **视觉**：1:1 还原原型配色、间距、动效与文案，不额外做设计升级。
5. **范围**：只重构原型已有能力，不新增登录、下单支付、真实地图、后台管理。

若以上有误，请直接改；确认后才开始写代码。

---

## 1. Objective

把单文件 HTML 原型重构为可维护的 Vue 3 工程，功能与交互与原型一致，数据与页面拆分为模块，便于后续接 API、登录和真实 AI。

**用户**：想「说走就走」的年轻旅行者，通过心情匹配开盲盒，随机解锁线路。

**核心闭环**：选心情 → 筛盲盒 → 开盒抽线路 → 写入行程/图鉴 → 可查看详情、生成日记、问 AI 搭子。

### 用户故事

| ID | 作为… | 我想… | 以便… |
|---|---|---|---|
| US-01 | 游客 | 按心情和分类浏览盲盒 | 快速找到适合当下状态的产品 |
| US-02 | 游客 | 花售价开一个盲盒 | 随机解锁价值保底 120% 的线路 |
| US-03 | 游客 | 在行程页查看已开线路 | 回顾目的地、亮点和包含服务 |
| US-04 | 游客 | 一键生成旅行日记 | 留下情绪化记录 |
| US-05 | 游客 | 和小途聊天 / 点快捷问句 | 获得旅行建议 |
| US-06 | 游客 | 完成 5 题人格测试 | 得到旅行人格和盲盒推荐 |
| US-07 | 游客 | 收集主题徽章 | 看到收集进度 |
| US-08 | 游客 | 在「我的」看统计 | 知道出行次数、省钱、等级 |

### 验收标准（可测试）

- 五 Tab 可切换：首页 / AI搭子 / 图鉴 / 行程 / 我的；当前 Tab 高亮为 `#FF6B35`。
- 心情与分类可叠加过滤；无结果时显示「暂无匹配的盲盒」。
- 开盒：1.2s 摇晃 → 翻牌结果；线路 `value >= minValue`；写入行程并可能解锁徽章。
- 刷新页面后，行程、徽章、等级仍在（`localStorage` key：`tujingxi_data`）。
- AI 聊天：关键词「散心/不好/emo」「周末/一日游」「一个人/安全」走固定回复，其余随机默认句。
- 人格测试 5 题，按最高分维度出 4 种人格之一。
- 空行程态文案与原型一致。
- 移动宽度（375px）布局不横向溢出，底部导航不遮挡内容。

## 5. Code Style

- 组件 `PascalCase.vue`；composable `useXxx.ts`；类型 `interface` 导出。
- 业务状态进 Pinia；一次性 UI（弹窗开关）可放组件或 `ui` store。
- 禁止在视图里直接 `innerHTML` 拼接业务数据；用模板绑定。
- Tailwind 工具类为主；仅动画/滚动条进全局 CSS。
- 文案与原型保持一致，不擅自改 slogan。

```ts
// 期望风格示例
export function pickRoute(box: BlindBox, pool: Route[]): Route {
  const valid = pool.filter((r) => r.value >= box.minValue)
  if (!valid.length) {
    throw new Error(`No route satisfies minValue=${box.minValue}`)
  }
  return valid[Math.floor(Math.random() * valid.length)]
}
```

## 7. Boundaries

**Always**

- 抽线路必须满足 `value >= box.minValue`。
- 用户数据读写统一走 storage 封装。
- 提交前跑 `npm run typecheck` 与 `npm run test`。
- 对照 `prototype/index.html` 核对文案和交互时机。

**Ask first**

- 加依赖、改存储结构、接真实 AI/支付、改成小程序。
- 新增登录、订单、退换真实流程。
- 改品牌色或信息架构。

**Never**

- 把密钥、真实用户数据提交进仓库。
- 开盒结果写死为固定线路冒充随机。
- 删除或改坏原型对照文件。
- 为通过测试而删失败用例。

### 8.3 首页

- AI 心情：😄开心 / 😔emo / 😶无聊 / 🤔迷茫（值：`happy|emo|bored|curious`）。
- 选中：`border-primary` + `bg-warm`。
- 提示文案：

| mood | 文案 |
|---|---|
| 默认 | 点击心情，AI为你推荐专属盲盒 |
| happy | 开心就要加倍！美食探店类盲盒超配你～ |

- 分类：全部 / 周边微度假 / 省内深度游 / 跨省限定 / 主题专线。
- 过滤：`category` 且（若已选心情）`box.mood` 包含当前心情。

### 8.4 开盒

1. 点「开盒」→ 弹窗展示名称、售价、保底。
2. 「立即开启惊喜」→ 礼盒 `shake` 1.2s。
3. 从 `routes[box.category]` 中筛 `value >= minValue`，均匀随机一条。
4. `trips.unshift`；若徽章未拥有则加入 `unlockedBadges`。
5. 翻牌展示线路；「查看行程」切到行程 Tab；「收下惊喜」仅关弹窗。

### 8.5 AI 搭子

- 开场白：「嗨～我是你的旅行搭子小途，不知道去哪玩都可以问我哦！」
- 快捷：推荐散心的地方 / 周末一日游推荐 / 一个人旅行安全吗。
- 回复延迟约 600ms。
- 用户气泡右对齐主色；AI 左对齐白底。

### 8.6 图鉴与测试

- 12 枚：古村、山野、美食、徽派、文艺、海滨、红色、乡村、探险、露营、研学、摄影。
- 未解锁：`grayscale + opacity 0.3`。
- 进度：`unlocked / 12`。
- 测试 5 题；累计维度分；取最高分对应人格（并列取遍历到的第一个最高分，与原型 `for...in` 行为对齐）。
- 四种结果：山野治愈家 / 城市探险家 / 追风冒险者 / 人文记录者。
- 「去解锁适合我的盲盒」关弹窗并回首页。

### 8.7 行程与日记

- 空态：「还没有开启旅程 / 去首页开一个盲盒吧」。
- 卡片：「已解锁」+ 购入价 / 票面价值；点击开底栏。
- 日记：按钮「AI生成中...」约 1s，三条模板随机一条，然后隐藏按钮。

### 8.8 我的与等级

| 出行次数 | 顶栏等级 |
|---|---|
| 0–2 | 旅行新手 |
| 3–7 | 探索者 |
| ≥8 | 旅行家 |

- 累计省钱 = Σ(`value - price`)。
- 已解锁线路数 = 徽章数（与原型一致，即 `unlockedBadges.length`）。
- 「当前等级」展示固定 `Lv.1`（原型如此，第一期不改）。
- 「公益里程」固定 `0`（原型如此）。
- 服务说明三块文案原样保留。

## 9. 数据模型

```ts
export type Mood = 'happy' | 'emo' | 'bored' | 'curious'
export type BoxCategory = 'nearby' | 'province' | 'cross' | 'theme'

export interface BlindBox {
  id: number
  name: string
  price: number
  minValue: number
  category: BoxCategory
  tag: string
  desc: string
  mood: Mood[]
}

export interface Route {
  name: string
  location: string
  value: number
  badge: string
  highlight: string
  include: string[]
  moodText: string
}

export interface Trip extends Route {
  id: number          // Date.now()
  boxName: string
  price: number
  date: string        // toLocaleDateString()
}

export interface PersistedState {
  unlockedBadges: string[]
  trips: Trip[]
  currentMood: Mood | null
  // 弹窗过程态不持久化
}
```

存储 key：`tujingxi_data`。读取失败时回退空状态，不抛到 UI。

**种子数据**：7 个盲盒、4 类线路池、12 徽章、聊天词库、5 题测试、4 个人格，与 `prototype/index.html` 逐条一致。实现时从原型迁入 `src/data/`，禁止凭记忆改数字或地名。
