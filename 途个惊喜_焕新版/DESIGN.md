# DESIGN.md — 途个惊喜 · 焕新版视觉设计稿

> 设计来源：产品页面原型（`docs/页面原型_副本.html`）与 Web 端（`index.html`）的同一套视觉系统——「烘焙店手账风」。PPT 不另起炉灶，直接长成产品的样子。

## 1. 画布与母版

- 画布 1280×720，页面 padding：上下 20px、左右 64px。
- **A · 标题块** 0–120px：章节编号（14px Caveat 手写体英文 + 22px 宋体小标）+ 主标题 34px 宋体 900，左侧；标题下 6px 鼠尾草绿短粗线（56×6px，圆角）。
- **B · 内容区** 120–660px（540px 可用）。
- **C · 页脚条** 660–720px：左侧「途个惊喜 · 随盒出发」13px muted，右侧页码 `NN / 15` 13px muted；页脚上方 1px 直线 #E7DCCE。
- 封面 / 结束页免 A/C 区，用自定义全幅版式。

## 2. 颜色系统（≤4 hex + 中性色）

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 · 鼠尾草绿 | `#8EA47C` | 标题短线、图标、图表主系列、强调块 |
| 主色深化 · 深鼠尾草 | `#6C7E58` | CTA、大标题强调字、表头、反白块 |
| 辅色 · 雾绿 | `#E4EDD8` | 卡片底、标签底、色块分区 |
| 强调色 · 腮红粉 | `#E8B4A2` | 仅焦点：锚点数字、重点标注（≤10%） |
| 背景 · 奶油白 | `#F6F1E6` | 全篇页面底色（中性） |
| 纸面 · 卡片白 | `#FFFDF8` | 卡片、表格底（中性） |
| 墨色 | `#3C342C` | 正文与标题（中性） |
| 灰褐 | `#8F8376` | 次要文字、页脚（中性） |
| 线条 | `#E7DCCE` | 分隔线、卡片描边（中性） |

**面积分配**：奶油白背景 ~55-65%，纸面卡片 ~15-25%，雾绿辅色 ≤20%，鼠尾草主色 ≤12%，腮红强调 ≤8%（Hero 页可到 15%）。
**渐变**：仅允许 `linear-gradient(180deg, #E4EDD8, #F6F1E6)` 用于云朵顶栏氛围；反白重点块用 `linear-gradient(135deg, #8EA47C, #6C7E58)`。
**纸张质感**：页面底层叠 3-4 个 `opacity: 0.5` 的雾绿/奶白圆形色块（绝对定位，不占安全区），模拟原型的云朵与手账氛围。

## 3. 字体系统

| 层级 | 字体 | 字号/字重 | 用途 |
|---|---|---|---|
| 封面主标 | Noto Serif SC（思源宋体） | 76px / 900 | 「途个惊喜」 |

| 巨型锚点数字 | Noto Serif SC | 72–96px / 900 | 01/02/03 序号、关键数字 |

| 卡片小标 | Noto Serif SC | 20–24px / 700 | 卡片头 |
| 正文 | Noto Sans SC（思源黑体） | 16–18px / 400-500 | 段落 |
| 手写点缀（仅英文/数字） | Caveat | 15–28px / 600-700 | 章节英文小标、页眉「Good Journey!」 |

fontFamily 写法：`'Noto Serif SC, serif'` / `'Noto Sans SC, sans-serif'` / `'Caveat, cursive'`。

## 4. 密度与留白

- 常规内容页留白 ≤ 32%；封面/结束页（留白型）≤ 50%。
- 每页 ≥1 个视觉锚点（≥44px 元素或 ≥40% B 区主视觉）；锚点周围 ≥40px 呼吸空间。
- 卡片填充率 ≥85%，尾部标签条用 `marginTop: 'auto'` 钉底；横向兄弟卡三段 y 轴对齐。
- 圆角语言：卡片 16-20px、标签 999px 胶囊、图片 14px；卡片阴影 `0 4px 16px rgba(60,52,44,0.06)`，描边 `1px solid #E7DCCE`。
